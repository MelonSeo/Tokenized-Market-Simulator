# 발표자 큐시트 — 2026-10-24

**기본안은 조회·보존 증거를 같은 순서로 반복한다.** 통합 소스의 컴파일/시험 통과와 모든 기능을 켠 하나의 운영 서버는 다르다. 거래·MetaMask 서명·유료 AI를 자동 실행하지 않는다. C 현재 잔고는 `1,000,003.066148919985598442 cMKRW`, CLOSED, free/locked/unpaid/pending=0, EOA nonce8/controller nonce2다.

## 시작 전 — 발표 T-45분, 리허설과 본 발표를 같은 1시간 안에

저장소 루트 기준, **보존된 원래 C 작업 공간**에서 실행한다. 새 공개 통합 소스에 비공개 snapshot/config를 복사하지 않는다.

```powershell
Set-Location deployment/runtime/dapp-c-development-worktree
python -B deployment/c-checkpoint-live-launch.py
# OFFLINE_PLAN_ONLY_NOT_STARTED와 parent=cdemo-8d5fd2ff832345bb 확인 후, 시작할 때만:
python -B deployment/c-checkpoint-live-launch.py --live-window
```

- `READY_BOUNDED_USER_WINDOW`가 나온 뒤 **출력된 readyFile**에서 `web`, `rpc`, `expiresAtEpoch`, `stopFile`을 확인한다. 기본 후보는 `http://127.0.0.1:32171/c-demo.html`, RPC `http://127.0.0.1:32172`, chainId31337이지만 **실제 READY 전에는 사용 가능으로 간주하지 않는다**. PowerShell 감독 프로세스를 닫지 않는다.
- 계정은 기존 `c-demo-user`; 비밀번호는 로컬 private 운영 기록에서만 확인한다. Git/화면 공유/대본에 넣지 않는다. MetaMask는 기존 독립 시험 지갑을 유지한다. `MetaMask 연결`은 연결 확인이며 서명이 아니다. 기존 연결이면 `소유 증명 및 계정 연결`을 반복하지 않는다.
- 최초 READY는 기존8 Receipt·계약/genesis·잔고·nonce·pending0을 검사한다. **C 전용 화면**이며 기존 시장/현물/legacy 선물/AI 전체 서버가 아니다.
- Oracle 시작부터 최대1시간 자동 종료이며 실제 만료시각은 readyFile을 따른다. 리허설·본 발표를 T-40분~T+15분 안에 마친다. 새 자산 이동 없이 조회만 반복하면 같은 거래·잔고를 보여줄 수 있다.
- 조기 종료는 readyFile의 `stopFile` 경로에 빈 STOP 파일을 **한 번 생성**하고, 감독 콘솔의 최종 보존 결과를 기다린다. 창 강제 종료·컨테이너 일괄 종료는 하지 않는다. 종료 후에는 **새 자손 checkpoint가 다음 정본**이다. 같은8d claim으로 다시 시작하지 않는다.

### 리허설 → 본 발표 반복 원칙

권장안은 동일한 1시간 창에서 **조회·PPT 증거 전환만 반복**하는 것이다. 새 거래가 없으므로 잔고/nonce/포지션 초기화가 필요 없다. MetaMask에서 실제 거래를 하면 값이 바뀌므로 원래 숫자를 계속 주장하지 않는다. 연습 자산을 초기화하거나 과거 거래를 재전송하지 않는다. 별도 연습 체인·금융 거래 환경은 이번에 새로 만들지 않았다.

### 현물 Playground 주의

기존 명령은 `deployment/runtime/integration-worktree`의 `python -B deployment/playground.py status|start|stop|account`, 후보 URL은 `http://127.0.0.1:25173`다. 이번 status는 정상응답/현재실행0이지만 **start 전 소스검사는 `identity/source changed; no automatic upgrade`로 차단**됐다. READY가 아니다. hash/manifest를 덮거나 새 초기 환경으로 대체하지 않았다. 오늘 대체 화면·검증 문서를 기본안으로 사용한다.

현재 서비스별 판정 및 Git 통합 결과는 [통합 보고서](../../claude-docs/presentation-integration-2026-10-24.md)를 따른다. 큐시트의 이미지와 과거 거래는 실제 증거이나, OFF 기능의 오늘 라이브 성공을 뜻하지 않는다.
